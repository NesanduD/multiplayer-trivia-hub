          How to play

          1. Connect

          Your browser opens a WebSocket to the Java server. That duplex channel carries the same game messages used by the TCP NIO clients.

          2. Create or join a room

          Rooms are managed by a multithreaded game engine. Open a second browser tab with another name to join the same room.

          3. Answer before time runs out

          Each question uses a scheduled timer (Callable/Future). Faster correct answers still score fixed points in this demo.

          4. Check stats

          When a match ends, results are saved and exposed via REST JSON endpoints — separate from the live play channel.

          Lecture mapping

          • TCP / sockets — framed JSON commands, connection lifecycle
          • Java NIO — non-blocking TCP server with Selector
          • UDP multicast — LAN server discovery beacons
          • Multithreading — concurrent rooms, synchronized scores, timers
          • HTTP + REST — leaderboard & history JSON APIs
